# Architektur
SonicForge besteht aus getrennten Modulen. `Core` enthält Modelle und Verträge, `Library` scannt lokale Dateien, `App` stellt die WPF-Oberfläche bereit. Audioverarbeitung, CD-Import, Radio, Podcasts und Spotify werden später als getrennte Module ergänzt. Spotify bleibt strikt vom Aufnahme- und Exportpfad getrennt.
